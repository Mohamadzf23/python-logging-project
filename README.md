# Python Logging Project

A practical Python project demonstrating how to use Python's built-in
logging module in a small multi-file application.

## Features

- Logging levels
- Custom logger configuration
- Formatter
- RotatingFileHandler
- File logging
- Custom exceptions
- Exception logging
- Username validation
